# MK Graffle releases

Free diagramming app for Mac and Windows: flowcharts, org charts, mind maps, network diagrams and wireframes,
exported as PDF, PNG, JPG, SVG or a clickable HTML page. No licence key, account or paid tier.

## Download

Get the installers from the [latest release](../../releases/latest):

| File | For |
| --- | --- |
| `MK.Graffle.1.1.macOS.dmg` | Macs on macOS 13 or later (Apple silicon and Intel) |
| `MK.Graffle.1.1.Setup.Windows.x64.exe` | Most Windows PCs. Installs for the current user, no admin rights needed |
| `MK.Graffle.1.1.Setup.Windows.ARM64.exe` | Windows on ARM (Snapdragon) |
| `MK.Graffle.1.1.Portable.Windows.x64.exe` | Runs without installing |

**First launch.** The builds are not signed by a paid developer account, so:

- **macOS:** right-click the app in Applications, choose **Open**, then **Open** again. If macOS says it is damaged, run
  `xattr -dr com.apple.quarantine "/Applications/MK Graffle.app"` once.
- **Windows:** on "Windows protected your PC", click **More info → Run anyway**.
